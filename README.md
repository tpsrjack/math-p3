# เฉลยคณิตศาสตร์ ป.3 (เว็บแอป)

เว็บแอปดูเฉลยคณิตศาสตร์ ป.3 เล่ม 1–2 ที่เปิดได้ทันที แปลง PDF เป็นรูปภาพรายหน้าไว้ล่วงหน้า
รองรับมือถือ มี PWA (ติดตั้งลงหน้าจอโฮม) และอ่านต่อแบบออฟไลน์ได้

**ออนไลน์:** https://tpsrjack.github.io/math-p3/

## วิธีใช้

| ทำอะไร | วิธี |
| --- | --- |
| ไปหน้าที่ต้องการ | พิมพ์เลขหน้าในช่อง **หน้า** แล้วกด **Enter** หรือ **ไป** |
| เปลี่ยนหน้า | ปุ่ม `‹` `›` / ลูกศร `←` `→` / ปัดซ้าย–ขวา (ตอนไม่ซูม) |
| ข้ามบท | แตะปุ่มบทที่แถบใต้ช่องเลขหน้า |
| สารบัญภาพ | ปุ่ม **▦** หรือกด `G` |
| ซูม | ปุ่ม `+` `−` / `Ctrl`+ล้อเมาส์ / ดับเบิลคลิก / **หุบ-กาง 2 นิ้ว** / ดับเบิลแท็บ |
| ติดตั้งแอป | กดปุ่ม **⤓** บนแถบด้านบน (เฉพาะเบราว์เซอร์ที่รองรับ) |
| ออฟไลน์ | หลังเปิดครั้งแรก Service Worker จะเก็บแอปและรูปที่เคยดูไว้ |

**เลขหน้า** คือเลขหน้าของเล่มเฉลย (มุมล่างของหน้า): เล่ม 1 = 1–205, เล่ม 2 = 1–199
(เลขในวงกลมมุมบนเป็นเลขหนังสือเรียนและถูกตัดขอบสแกนไป จึงใช้ค้นหาไม่ได้)

## เปิดในเครื่อง (ทางเลือก)

ดับเบิลคลิก **`เปิดเฉลย.bat`** หรือเปิด `index.html` ด้วยเบราว์เซอร์
หรือรัน `python -m http.server 8777` ในโฟลเดอร์นี้ แล้วเปิด http://127.0.0.1:8777

## โครงสร้าง

```
math-p3/
├─ index.html / styles.css / app.js / data.js
├─ manifest.webmanifest / sw.js / icons/     → PWA
├─ pages/      ภาพปกติ 150 dpi (739 px)
├─ pages-hd/   ภาพความละเอียดสูง 220 dpi (1084 px) ใช้ตอนซูม/จอ retina
├─ thumbs/     ภาพย่อสำหรับสารบัญภาพ (~150 px)
├─ tools/      build_pages.py, make_icons.py
└─ เปิดเฉลย.bat
```

ภาพปกติ + HD รวม ~43 MB, 404 หน้า

## Build ใหม่เมื่อเปลี่ยน PDF

```powershell
python tools\build_pages.py --force   # ต้องมี pymupdf + pillow
python tools\make_icons.py            # สร้างไอคอน PWA ใหม่ (ถ้าต้องการ)
```

แก้ path PDF และรายการ `chapters` (บทที่, ชื่อบท, หน้าเริ่ม) ใน `tools/build_pages.py` ก่อนรัน
หน้าเริ่มของแต่ละบทดูจากหน้า "เตรียมความพร้อม"

## อัปเดตขึ้น GitHub Pages

ทุกครั้งที่แก้ไฟล์แล้ว `git push origin main` → GitHub Pages จะ build ใหม่เอง
ถ้าแก้ไฟล์หลัก (html/css/js/manifest) ให้เพิ่ม `VERSION` ใน `sw.js` ด้วย เพื่อล้างแคชเก่าของผู้ใช้
